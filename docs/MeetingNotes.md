# センチメント判定データフロー (Sentiment Calculation Flow)

入力されたマルチアセットのデータ（Inputs）から総合スコア（Score）を算出し、最終的な市場環境（Risk ON / Risk OFF / Neutral）を判定するシステムフローです。

---

## 🔄 データフロー図 (Data Flow)

```text
                  Inputs
 ┌──────────────────────────────────────┐
 │ SP500  │ NASDAQ │ US10Y │ Gold │ DXY │
 │ USDJPY │ BTC    │ ETH   │ VIX  │     │
 └──────────────────┬───────────────────┘
                    │
                    ▼
                  Score
 ┌──────────────────────────────────────┐
 │       各アセットのスコア集計        │
 └──────────────────┬───────────────────┘
                    │
                    ▼
            Sentiment Result
 ┌──────────────────────────────────────┐
 │   🟢 Risk ON                         │
 │   🔴 Risk OFF                        │
 │   ⚪ Neutral                         │
 └──────────────────────────────────────┘
📥 入力パラメータ (Inputs)
分析対象となる9つの主要アセットです。

分類	アセット名	記号	主な役割・指標
株価指数	S&P 500	SP500	米国主要500社の株価動向（リスク資産）
株価指数	NASDAQ	NASDAQ	ハイテク株中心の株価動向（高βリスク資産）
金利 / 債券	米国10年債利回り	US10Y	米国長期金利（金利上昇＝債券安）
コモディティ	金（ゴールド）	Gold	安全資産 / インフレヘッジ
為替	ドル円	USDJPY	リスクオン時の円安・ドル高傾向
為替	ドルインデックス	DXY	米ドルの総合的な強弱
暗号資産	ビットコイン	BTC	グローバルなリスクオンセンチメント
暗号資産	イーサリアム	ETH	アルトコイン・Web3全般のリスク許容度
ボラティリティ	VIX指数	VIX	市場の恐怖指数（高VIX＝リスクオフ）
🧮 スコアリング & 最終判定 (Score & Decision)
各アセットの状態（移動平均線との位置関係、前日比など）から数値を算出し、合算値（Score）に基づいて市場環境を出力します。

判定条件一覧
🟢 Risk ON

条件: Score ≧ 閾値（例: +5.0）

状態: 株高・暗号資産高・円安・金下落・VIX低下などが優勢

🔴 Risk OFF

条件: Score ≦ 閾値（例: -5.0）

状態: 株安・暗号資産安・円高・金買われ・VIX急騰などが優勢

⚪ Neutral

条件: -5.0 ＜ Score ＜ +5.0

状態: アセット間で強弱が拮抗しており、明確なトレンドがないレンジ状態
