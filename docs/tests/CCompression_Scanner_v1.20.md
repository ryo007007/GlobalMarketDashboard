CCompression Scanner v1.20

追加機能:
- TRANSITION開始時のATRを記録
- 指定計測本数終了時に上方ブレイク / 下方ブレイク / だまし候補 / 不発 / 方向感なし / 方向未確定を判定
- 判定結果と判定根拠をCSVの「補足」欄へ記録
- 直近の判定結果をスキャナー行に表示
- 判定結果を端末グローバル変数へ保存し、チャート切替後も表示を維持
- CSVファイル名をv1.20に分離

重要:
このMQ5は、元のv1.15と同じ外部include構成を前提とします。
次の2ファイルが元の相対パスに存在する必要があります。
  CCompressionScannerCompat.mqh
  ../src/Modules/Engines/SuddenMoveDetector.mqh

このZIPには上記includeファイルは含まれていません（元のv1.15 ZIPにも含まれていなかったため）。
MetaEditorでコンパイルし、include不足エラーが出る場合は、元のプロジェクト一式を同じフォルダ構成で配置してください。

判定は開始時ATRに対する終値変化を基本にしたルールベースです。売買シグナルや将来予測ではなく、TRANSITION後の値動きの事後分類です。
既存の圧縮検出条件・スコア計算・急変検知条件は変更していません。
