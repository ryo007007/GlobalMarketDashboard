# 通貨モメンタム計算ロジック説明書

## 1. 概要

本ドキュメントでは、Global Market Dashboard Ultimate の `CurrencyStrength.mqh` に実装されている、通貨モメンタム（Currency Momentum）の計算方法を説明します。

通貨モメンタムは、主要8通貨について、直近の確定ローソク足の方向を通貨ペアごとに集計し、上昇方向と下落方向のどちらに偏っているかを示す数値です。

### モメンタムの目的

- 直近の値動きが、どちらの方向に偏っているかを把握する。
- 通貨強弱スコアとは別の視点から、通貨の状態を確認する。
- 集計結果を矢印に変換し、ダッシュボード上で視覚的に表示する。

**重要：** 現在の実装は、価格変動率や値幅から勢いの大きさを計算するものではありません。ローソク足の上昇・下落方向を点数化する方式です。

## 2. 対象通貨

通貨強弱エンジンと同じく、以下の8通貨を対象とします。

| 通貨コード | 通貨名 |
|---|---|
| USD | 米ドル |
| EUR | ユーロ |
| JPY | 日本円 |
| GBP | 英ポンド |
| CHF | スイスフラン |
| CAD | カナダドル |
| AUD | 豪ドル |
| NZD | ニュージーランドドル |

対象となる28通貨ペアについて、直近の確定ローソク足を評価します。

## 3. 計算対象のローソク足

モメンタムの計算対象は、各通貨ペアの直近の確定足です。

MetaTrader 5 では、通常、次のように扱います。

- `Shift 0`：形成中のローソク足
- `Shift 1`：直近の確定ローソク足
- `Shift 2`：2本前の確定ローソク足

現在の実装では、モメンタムの計算に `Shift 1` を使用します。

そのため、形成中のローソク足の値動きによってモメンタムの点数が変化する方式ではありません。新しいローソク足が確定し、計算が更新されたときに結果が変化します。

## 4. 基本計算式

各通貨ペアについて、直近の確定足の始値と終値を比較します。

| 条件 | 基軸通貨への加点 | 決済通貨への加点 |
|---|---:|---:|
| 終値 > 始値（陽線） | +1 | -1 |
| 終値 < 始値（陰線） | -1 | +1 |
| 終値 = 始値 | 0 | 0 |

ここでいう基軸通貨と決済通貨は、実際に取得した銘柄の通貨順序を基準とします。銘柄の通貨順序が標準の組み合わせと逆になっている場合は、実装内で通貨の対応関係を入れ替えて処理します。

### 4.1 EURUSDの計算例

EURUSD が陽線だった場合：

- EUR（ユーロ）：+1
- USD（米ドル）：-1

EURUSD が陰線だった場合：

- EUR（ユーロ）：-1
- USD（米ドル）：+1

このように、各通貨ペアの値動きを、関係する2通貨のモメンタムへ反映します。

## 5. 通貨ごとの集計

各通貨について、28通貨ペアのうち、その通貨が関係するペアの加点・減点を合計します。

概念的な計算式は次のとおりです。

`通貨モメンタム = 各通貨ペアから受け取った加点・減点の合計`

数式で表すと、次のようになります。

$$
S = \sum_{i=1}^{n} x_i
$$

Σ（シグマ）＝各項目の合計

\[
M_c=\sum_{p=1}^{28}\Delta_{c,p}
\]

- \(M_c\)：通貨 \(c\) のモメンタム
- \(\Delta_{c,p}\)：通貨ペア \(p\) から通貨 \(c\) に加算される値（+1、-1、0）

実際には、その通貨が関係するペアの値だけが加算されます。

各通貨は他の7通貨と組み合わせられるため、すべてのペアのデータが正常にそろっている場合、1通貨のモメンタムは理論上 -7 から +7 の範囲になります。

## 6. モメンタムと通貨強弱スコアの違い

モメンタムと通貨強弱スコアは、異なる目的で計算されます。

| 項目 | 通貨強弱スコア | 通貨モメンタム |
|---|---|---|
| 主な目的 | 通貨の相対的な強さを比較する | 直近の方向の偏りを把握する |
| 対象ローソク足 | 設定された複数の確定足 | 直近の確定足（Shift 1） |
| 重み付け | 設定に応じて適用 | 適用しない |
| 計算方法 | ローソク足方向の点数を集計 | +1、-1、0を集計 |
| 出力 | 0〜100のスコア | 整数のモメンタム値 |
| 表示 | 通貨強弱ランキングなど | 矢印表示 |

通貨強弱スコアが高くても、直近のモメンタムがマイナスになることがあります。

これは、過去の複数の確定足では相対的に強かった通貨が、直近の確定足では弱い方向に動いたことを示す場合があります。

## 7. モメンタム値から矢印への変換

現在の `GetArrow()` 関数では、モメンタム値を7段階の矢印表示に変換します。

| モメンタム値 | 表示 | 判定 |
|---:|:---:|---|
| +6以上 | ↑↑↑ | 強い上向き |
| +3〜+5 | ↑↑ | 上向きが優勢 |
| +1〜+2 | ↑ | 上向き |
| 0 | → | 中立 |
| -1〜-2 | ↓ | 下向き |
| -3〜-5 | ↓↓ | 下向きが優勢 |
| -6以下 | ↓↓↓ | 強い下向き |

この表示は、モメンタムの点数に基づく方向の分類です。

「↑↑↑」は価格上昇率が大きいことを直接意味するものではなく、「直近の確定足に基づく集計値が +6 以上である」ことを意味します。

## 8. 計算例

ある通貨が関係する7通貨ペアについて、直近の確定足が次の状態だったとします。

| ペアの判定 | 対象通貨への点数 |
|---|---:|
| 上昇方向に加点されるペア | +1 |
| 上昇方向に加点されるペア | +1 |
| 上昇方向に加点されるペア | +1 |
| 下落方向に加点されるペア | -1 |
| 上昇方向に加点されるペア | +1 |
| 変化なし | 0 |
| 下落方向に加点されるペア | -1 |
| **合計** | **+2** |

この場合、モメンタムは +2 となり、矢印表示は `↑` です。

なお、これは計算方法を説明するための仮例であり、特定の通貨の実測結果ではありません。

## 9. 現在の方式の特徴と制約

### 9.1 特徴

- 計算が比較的シンプルである。
- 直近の確定足を利用するため、形成中の足による頻繁な変動を避けられる。
- 複数通貨ペアの情報を1つの通貨別スコアに集約できる。
- 通貨強弱ランキングと組み合わせて利用できる。

### 9.2 制約

- ローソク足の値幅を直接評価しない。
- 価格変動率を直接評価しない。
- 直近1本の確定足に基づくため、短期的な値動きの影響を受ける。
- データが不足している場合、理論上の最大・最小値に達しないことがある。
- 矢印は将来の値動きや取引利益を保証しない。

特に、同じ +1 であっても、小さな陽線と大きな陽線を区別しない点に注意が必要です。

## 10. 今後の改善候補

以下は将来の検討項目です。実際に実装・検証されるまでは、現在の機能として扱いません。

- 価格変動率に基づくモメンタムの追加
- 複数時間足によるモメンタムの比較
- 直近数本のモメンタム変化を利用した加速・減速の判定
- 通貨強弱スコアとモメンタムの方向一致度の評価
- Compression Scanner との連携
- Money Flow Engine との連携
- 過去データおよびデモトレードによる有効性の検証

改善を行う場合も、現在の方向スコアと新しい値幅ベースの指標を区別することで、既存表示の意味を維持しながら機能を拡張できます。

## 11. ソースコードとの対応

本ドキュメントは、以下の実装を基準にしています。

- ファイル：`src/Modules/Engines/CurrencyStrength.mqh`
- モメンタムの格納先：`m_momentum`
- モメンタムの計算：`CCurrencyStrength::Calculate()`
- モメンタムの取得：`CCurrencyStrength::GetMomentum()`
- 矢印への変換：`CCurrencyStrength::GetArrow()`

モメンタムの加算処理では、`shift == 1` のときにのみ加点・減点を行っています。

矢印表示の閾値は `GetArrow()` 関数に定義されています。

## 12. まとめ

現在の通貨モメンタムは、価格変動幅を測る指標ではなく、直近の確定ローソク足の方向を8通貨の関係性から集計する指標です。

- **通貨強弱：** どの通貨が相対的に強いか
- **モメンタム：** 直近の確定足で、どちらの方向に点数が偏ったか

この2つを組み合わせることで、相対的に強い通貨と、直近の方向が一致しているかどうかを確認できます。

ただし、実際の取引で有効かどうかは、価格変動や相場環境も含めて検証する必要があります。

## 通貨モメンタムの計算式

### 1. 基本計算

通貨ペアの直近確定足（Shift 1）の方向を判定し、基軸通貨と決済通貨にスコアを加算します。

**陽線の場合**

$$
M_{\text{base}} \mathrel{+}= 1
$$

$$
M_{\text{quote}} \mathrel{-}= 1
$$

**陰線の場合**

$$
M_{\text{quote}} \mathrel{+}= 1
$$

$$
M_{\text{base}} \mathrel{-}= 1
$$

**始値と終値が同じ場合**

モメンタムは更新しません。

### 2. 記号の意味

- \(M_{\text{base}}\)：基軸通貨のモメンタム
- \(M_{\text{quote}}\)：決済通貨のモメンタム
- \(+1\)：上昇方向への1票
- \(-1\)：下降方向への1票

### 3. 集計の考え方

各通貨について、関連する通貨ペアの判定結果を合計します。

$$
M_c = \sum_{i=1}^{N_c} m_{c,i}
$$

ここで、\(M_c\) は通貨 \(c\) のモメンタム、\(N_c\) はその通貨が参加する通貨ペア数、\(m_{c,i}\) は各通貨ペアから得られる投票値です。

8通貨・28通貨ペアがすべて利用可能な場合、各通貨は7通貨ペアと比較されるため、理論上の範囲は \(-7\) から \(+7\) です。

※ この集計式は、MQL5コードの計算を数式で表したものです。モメンタムは値動きの大きさや加速度ではなく、直近確定足の方向を集計した指標です。
