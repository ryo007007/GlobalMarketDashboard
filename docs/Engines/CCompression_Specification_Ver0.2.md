# CCompression Specification Ver.0.2

## 1. 目的

CCompression は、市場の変動幅の縮小を中心として、市場がCompression状態にある可能性を検出し、その後の状態変化を観測する。ADXはトレンド強度を評価する補助指標として使用する。

### 重要
CCompression は以下を**行わない**：
- 上昇予測
- 下落予測
- ブレイクアウト予測
- 方向判定

あくまで以下の市場状態を検出する：
```
NORMAL → COMPRESSION → STRONG COMPRESSION → TIGHT COMPRESSION → TRANSITION
```

## 3. ATR

| 項目 | 設定 |
|------|------|
| Period | ATR(14) |
| Raw | `ATR% = ATR(14) / Close × 100` |
| Percentile | 過去 125 期間の ATR% 分布における現在値のパーセンタイル |

### Score
| Percentile | Score |
|------------|-------|
| 0 ～ 20    | 2     |
| >20 ～ 35  | 1     |
| >35        | 0     |

---

## 4. Bollinger Band Width

| 項目 | 設定 |
|------|------|
| Period | 20 |
| Deviation | 2.0 |
| Raw | `BB Width = (Upper Band - Lower Band) / Middle Band × 100` |
| Percentile | 過去 125 期間と比較 |

### Score
| Percentile | Score |
|------------|-------|
| 0 ～ 10    | 2     |
| >10 ～ 20  | 1     |
| >20        | 0     |

※ Compression 指標として特に重要。

---

## 5. 20期間 Range

| 項目 | 設定 |
|------|------|
| Raw | `Range20% = (Highest High[20] - Lowest Low[20]) / Close × 100` |
| Percentile | 過去 125 期間と比較 |

### Score
| Percentile | Score |
|------------|-------|
| 0 ～ 20    | 2     |
| >20 ～ 40  | 1     |
| >40        | 0     |

---

## 6. ADX

| 項目 | 設定 |
|------|------|
| Period | ADX(14) |
| 判定方式 | Percentile ではなく**絶対値**を使用 |

ADXについてはATR等と違って、Percentileではなく絶対値から開始する。  
ADXはCompressionの必須条件ではなく、トレンド強度を評価する補助スコアとして使用する。

### Score
| ADX値     | Score |
|-----------|-------|
| < 15      | 2     |
| 15 ～ <20 | 1     |
| ≥ 20      | 0     |

## 7. Compression Score

4 指標の合計：

```
ATR       0～2
BB Width  0～2
Range20   0～2
ADX       0～2
----------------
Total     0～8
```

### 状態定義
| Score | State                |
|-------|----------------------|
| 0～2  | NORMAL               |
| 3～4  | COMPRESSION          |
| 5～6  | STRONG COMPRESSION   |
| 7～8  | TIGHT COMPRESSION    |

※ 本値は Ver.0.1 の仮説値とする。

## 8. 状態遷移（Delta による観測）

Ver.0.2 では、正式な `BUILDING` / `RELEASE` 状態は持たない。

現在取得可能な情報は以下：
- Score
- Previous Score
- Delta
- Age
- State

**Delta から Compression の強弱変化を観測する。**

例：
- Score 3 → 4（Delta +1） → Compression Strengthening
- Score 5 → 4（Delta -1） → Compression Weakening

将来 Dashboard で `BUILDING` / `RELEASING` 表示を追加するのは別の改良として扱う。

---

## 9. TRANSITION

**TRANSITION は、単なる Score 低下では発生させない。**

以下の **3 条件をすべて満たした場合** に TRANSITION とする。

### 条件A
前回状態が以下のいずれか：
- STRONG COMPRESSION
- TIGHT COMPRESSION

### 条件B
```
Current Score < Previous Score
```

### 条件C
現在の値が前回値より上昇している：
```
ATR% > 前回ATR%
または
BB Width > 前回BB Width
```

3 条件を満たすと `TRANSITION` となる。

---

## 10. 方向判定を行わない

CCompression は「圧縮が解除され始めた」ことまでを検出する。

その後の方向は以下の別 Engine から取得する：

```
CCompression
      ↓
TRANSITION
      │
      ├── Currency Strength
      ├── Strength Gap
      ├── Money Flow
      └── Market Regime
```

CCompression 自身が方向性を出力しない設計を維持する。

### 追加原則（Ver.0.2）
- CCompression は「波及先の予測」も「先行・追随の確定」も行わない。
- 市場間の関係は「観測済み」「仮説」「未確認」に分類し、推測を確定シグナルのように見せない。
- 「先行して動いた」という事実と、「予測に役立つ」という事実は別物として扱う。

## 12. Delta

```
Delta = Current Score - Previous Score
```

例：
- 2 → 3 = +1
- 3 → 5 = +2
- 4 → 3 = -1

Compression の強さが強まっているか弱まっているかを示す指標。

---

## 13. Age

```
Age = 現在の STATE が何回連続して続いているか
```

実装ルール：
- 前回 State == 今回 State → Age + 1
- State が変化 → Age = 1

例（H4 の場合）：
```
H4 #1  NORMAL
H4 #2  COMPRESSION  → Age 1
H4 #3  COMPRESSION  → Age 2
H4 #4  COMPRESSION  → Age 3
H4 #5  COMPRESSION  → Age 4
H4 #6  NORMAL       → Age 1（リセット）
```

## 17. 市場活動度一覧（第2段階仕様）

### 17.1 目的

「価格が上がった市場」を活発とするのではなく、普段と比べて値動きや状態変化がどれほど大きくなっているかで判断する。最初は方向予測を付けない。

### 17.2 観項目

| 観測項目 | 見たいもの |
|---------|-----------|
| 値動きの大きさ | ATR比などで、普段より大きく動いているか |
| 急変の強さ | ROC Zなどで、変化が急激か |
| 圧縮からの変化 | COMPRESSIONからTRANSITIONへ移ったか |
| 継続性 | 一瞬のヒゲだけか、複数本にわたり動いているか |
| 市場間の広がり | 1銘柄だけか、関連市場にも変化が広がっているか |

### 17.3 通貨強弱の観点

たとえば EUR/USD、EUR/JPY、EUR/CAD がほぼ同じ時間に下落した場合、3つの独立した出来事として数えるだけでは不十分である。EUR が共通しているため、EUR を含む通貨ペアに共通した動きが起きている可能性を考える。

ただし、EUR の弱さが原因なのか、USD や JPY 側の動きなのかは、各通貨の強弱や他のペアも見て判断する。

### 17.4 出力イメージ（案）

```
## Market Activity Monitor（観測用）

| Market | Symbol | Activity Level | ATR Ratio | State Change | Notes |
|--------|--------|---------------|-----------|--------------|-------|
| FX | EUR/USD | High | 1.8x | TRANSITION | EUR weakness suspected |
| FX | EUR/JPY | High | 2.1x | TRANSITION | Same cluster as EUR/USD |
| FX | USD/JPY | Normal | 1.0x | COMPRESSION | - |
| Crypto | BTC/USD | Elevated | 1.5x | NORMAL | ATR rising |
```

> **注記：上記の「Notes」欄の記述は仮説であり、確定ではない。「suspected」などの表現を用い、推測を確定として見せない。**

## 18. 金利監視項目（将来拡張）

単に米国10年債利回りを表するだけでなく、将来的には金利を以下の視点に分けて監視する。

| 指標候補 | 何を見たいか |
|---------|------------|
| 米国2年債利回り | 政策金利見通しの変化に比較的敏感 |
| 米国10年債利回り | 長期金利の上昇・低下 |
| 米国10年実質金利 | インフレ期待を考慮した金利環境 |
| 2年・10年の利回り差 | 短期と長期の金利見通しの変化 |

### 18.1 観測上の注意

- 高金利そのものだけでなく、金利が**急速に上昇していること**にも注意する。
- 金利上昇と Nasdaq 下落が同時に起きた場合、株式の評価に影響する金利上昇が関係している可能性がある。
- 一方、景気悪化への懸念から金利が低下して株式も下落することもある。
- **したがって、金利の水準だけでリスクオン・オフを決めない設計とする。**

## 19. 開発ロードマップ（段階的実装計画）

CCompression の軸を保ちながら、Global Market Dashboard へ段階的に発展させる順序。

### 第1段階：CCompression の検証を継続（現在）
- 圧縮検出、TRANSITION、急変検知の時刻と、その後の値動きを記録する。
- 現状の検出条件は維持する。
- 対象：個別チャート（主要FXペア、GOLD等）。

### 第2段階：市場活動度の一覧を作る
- FX、暗号資産、商品、株式指数、VIX、債券について、値動きの強さと状態変化を一覧化する。
- 最初は方向予測を付けない。
- 出力は「観測済み」のみとし、仮説は明確に区別する。

### 第3段階：先行・追随の記録を追加する
- 市場間の変化時刻を比較し、5分・15分・30分などの時間差を調べる。
- セッションや経済指標発表の影響も区別する。
- 「先行した」とは記録するが、「予測に役立つ」かどうかは別途検証する。

### 第4段階：波及仮説を表示する
- 再現性が確認できた関係だけを使い、「追随の可能性」などとして表示する。
- 表示を「観測済み」「仮説」「未確認」に分け、推測を確定シグナルのように見せない。

### 5段階：方向・時間の予測を検証する
- 「15分後に上昇」「30分後に下落」といった予測は、過去データで精度を評価してから追加する。
- 精度が検証されるまでは、予測機能を本番表示に組み込まない。

### 当面の推奨
- 第1段階を続けながら、第2段階の仕様だけを整理する。
- 新しい市場分析機能をいきなり実装する必要はない。

## 20. 設計原則と制約

### 20.1 観測と仮説の分離
- 観測された事実（State, Delta, TRANSITION, ATR変化など）と、仮説（波及先、先行・追随、通貨強弱の原因など）を明確に分離する。
- 仮説は「観測済み」「仮説」「未確認」に分類して表示する。

### 20.2 確定シグナルとして見せない
- 「追随の可能性」「EUR弱さの疑い」など、不確実性を含む表現を用いる。
- 数値や方向を予測する場合は、信頼区間や過去の再現性を併記する。

### 20.3 「先行した」≠「予測に役立つ」
- 最初に動いた市場を特定することだけが目的はない。
- その先行変化が、他の市場の値動きを予測するのに役立つかどうかを、過去データで検証する必要がある。
- この違いを守ることで、CCompression から脱線せず、将来の Global Market Dashboard につながる形で整理する。

### 20.4 CCompression の軸の維持
- CCompression はあくまで「圧縮とその解除の検出」に特化する。
- 市場間分析、方向予測、波及予測は、CCompression の上に構築する別層の機能と置づける。
