# examples/

このフォルダには、ダッシュボードのスクリーンショットや使用例を配置します。

## 推奨ファイル

| ファイル | 内容 |
|----------|------|
| `Dashboard.png` | メインダッシュボード全体 |
| `CurrencyStrength.png` | 通貨強弱ランキング拡大 |
| `MoneyFlow.png` | Money Flow 表示（Ver2.20 以降） |
| `HybridMode.png` | チャート＋Dashboard 同時表示 |
| `MinimalMode.png` | 最小表示モード |

> 画像は実際の MT5 画面キャプチャを推奨します。  
> リポジトリに含める際はファイルサイズに注意し、必要なら圧縮してください。
